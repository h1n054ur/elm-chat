# Security

This instance has not been independently audited. What it does and does not protect is listed at https://chat.h1n054ur.dev/limits and in [docs/threat-model.md](docs/threat-model.md).

Vulnerabilities in the protocol, crypto or room lifecycle almost certainly affect upstream elm.chat too: report them privately through [upstream's security advisories](https://github.com/shawnbure/elm-chat/security/advisories/new). Do not open public issues for them.
